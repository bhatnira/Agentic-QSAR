============================================================
PROJECT
============================================================

Project name:

Chemically Trustworthy Agentic QSAR

Short name:

CTA-QSAR

Core concept:

Build an autonomous scientific agent that receives a previously unseen QSAR
dataset and determines how the dataset should be modeled.

The agent must autonomously:

1. inspect the dataset;
2. identify the molecular structure column;
3. identify the endpoint/target column;
4. infer the endpoint/task type;
5. characterize the dataset;
6. perform chemical/data quality control;
7. identify the appropriate validation strategy;
8. identify candidate molecular representation spaces;
9. identify candidate modeling paradigms;
10. select computationally efficient experiments;
11. train/evaluate models;
12. assess predictive performance;
13. assess chemical trustworthiness;
14. diagnose weaknesses;
15. propose corrective interventions;
16. run additional experiments;
17. compare previous and new evidence;
18. stop when further experimentation is not worthwhile;
19. produce a reproducible final scientific report.

This is NOT simply AutoML.

The central research idea is:

AUTONOMOUS MODELING-STRATEGY DISCOVERY AND SELF-CORRECTION FOR
CHEMICALLY TRUSTWORTHY QSAR.

B. What is known about the dataset?

C. What are the important risks?

D. Which validation strategy is scientifically appropriate?

E. Which representations are plausible?

F. Which modeling paradigms are computationally feasible?

G. Which experiment has the highest expected scientific value?

H. What happened?

I. What failed?

J. What intervention is justified?

K. Is another experiment worthwhile?

This should be implemented as explicit structured state.
